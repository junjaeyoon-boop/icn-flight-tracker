# 인천공항 비정상 운항 현황 (안내데스크용)

결항·회항·지연편을 10분마다 자동 수집해 한 화면에 보여주고, 항공사에 확인한 내용(사유·카운터·게이트·보상)을 편별로 기록해 바로 안내·전달할 수 있게 만든 페이지입니다.

## 화면 기능
- **요약 타일**: 결항 / 회항 / 지연(기준 선택: 30분~3시간) / 미확인 신규 — 누르면 해당 편만 보기
- **검색**: 편명(공동운항 편명 포함)·항공사·도시·카운터·게이트. `/` 키로 바로 검색창 이동
- **전체 항공편 보기**: 비정상이 아닌 편도 검색 가능 (승객이 아무 편이나 물어볼 때)
- **편별 카드**: 예정→변경 시각, 지연 시간, 터미널, 체크인 카운터, 게이트, 수하물수취대·출구, 최초 감지 시각, 최근 변경
- **항공사 확인 내용 기록**: 사유 / 카운터 운영 / 게이트 운영 / 보상·지원 / 기타 / 확인자 + 항공사별 연락처 메모
- **승객 안내문 복사**: 편별 안내 문구 자동 생성
- **📋 전달문**: 결항·회항·지연 전체 목록을 메신저 전달용 텍스트로 (기존 수기 전달 대체)
- **변경 이력**: 시각·게이트·카운터·현황이 바뀐 시점 기록
- **신규 알림**: NEW 표시, 탭 제목에 건수, 알림음(선택)
- **수집 상태 표시**: API 오류나 30분 이상 갱신이 없으면 상단 경고

## 처음 설정 (1회)
1. 저장소 **Settings → Secrets and variables → Actions** 에 `SERVICE_KEY` (공공데이터포털 인증키, Decoding 키) 가 있는지 확인
2. **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 변경
3. **Actions** 탭 → *Update Flight Data* → **Run workflow** 로 첫 실행

이후 10분마다 자동 실행됩니다. (GitHub 예약 실행은 혼잡 시 몇 분~십여 분 늦어질 수 있어, 화면 상단의 수집 시각을 기준으로 보세요.)

## 알아둘 점
- 확인 내용·메모는 **그 PC의 브라우저에만** 저장되고 자정이 지나면 지워집니다. 여러 PC가 함께 보려면 공유 저장소(예: Google Sheets, Firebase)를 붙여야 합니다.
- 지연 사유·카운터/게이트 운영시간·보상은 공항 API에 없는 정보라 항공사 확인 후 직접 입력합니다.
- 로컬 테스트: `MOCK_DIR=모의응답폴더 python main.py` (폴더에 `D.json`, `A.json`) → `site/` 폴더 열기
